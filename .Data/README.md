# .Data/ — game-derived material (machine-local, never share)

Everything in here derives from your own legally-dumped copies of Pokémon
X/Y and from processing them. **Nothing under .Data/ is ever committed or
distributed** — game dumps, extracted assets, generated C, symbol maps,
port trees and binaries all carry Nintendo's IP and/or console-unique
keys. Per repo convention, dot-prefixed top-level dirs are machine-local
"agentic reference" material — only this README is tracked.

| Path | Contents |
|---|---|
| `Rom/X/Base/` | Pokémon X v1.0: `0004000000055D00_v00.3ds` (kujira-1) + decrypted `0004000000055D00.dec.code` — primary target |
| `Rom/Y/Base/` | Pokémon Y v1.0: `0004000000055E00_v00.3ds` (kujira-2) + decrypted code |
| `Rom/X/Upd/`, `Rom/Y/Upd/` | v1.5 update partitions — title `0004000E…` CXI + decrypted v1.5 `code.bin` (5,169,152 B) |
| `Rom/nand/` | console key material (`boot9.bin`, `firm0.bin`, `otp.mem`) — highest sensitivity |
| `Raw_Extracted/` | raw decrypted partitions (`romfs/`, `exefs/`, `part1_romfs/`, `part7_romfs/`) — treat as **read-only sources** |
| `Source_Extracted/` | all derived output — index in `Source_Extracted/MAP.md` |
| `Source_Extracted/garc/` | 272 GARCs unpacked (44,519 files) + `manifest.tsv` |
| `Source_Extracted/decomp/` | Ghidra project + 38,385 decompiled C functions |
| `Source_Extracted/cro/` | 133 plaintext CRO modules + `static.crs` |
| `Source_Extracted/pipeline/` | matching-decomp workspace: `orig/`, `symbols/` CSVs, generated `split/`, `out/` (134/134 byte-identical recreates), `objdiff.json` |
| `Source_Extracted/recomp/` | 3dsrecomp analyze/build output + the standalone port project (`port/`) |
| `Source_Extracted/curated/` | `xy curate` output tree |
| `Curated/ports/` | port trees generated by `xy-recomp/build.sh` |

Console key material (`Rom/nand/`, any `*.dec.code`) is named explicitly
in the repo `.gitignore` as belt-and-braces on top of the whole-tree
ignore.
